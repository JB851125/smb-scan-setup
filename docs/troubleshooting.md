# 除錯對照

掃描至資料夾失敗時，依下列順序排查，多數問題在前三項就能定位。

## 排查順序

1. **權限只做了一層** — 共用權限與 NTFS 權限都要給寫入，取較嚴格者生效
2. **防火牆未放行** — 事務機連不進電腦的 TCP 445 埠
3. **帳號或密碼問題** — 密碼已到期，或使用者名稱未加電腦名稱前綴
4. **路徑錯誤** — 主機欄與路徑欄重複填寫 IP，或共用名稱打錯
5. **IP 已變動** — 電腦重新取得不同的 DHCP 位址
6. **防毒軟體攔截** — 端點防護阻擋 SMB 連線或共用資料夾寫入

## 錯誤碼對照

部分機種會顯示數字錯誤碼，常見對應如下。實際定義請以各廠牌官方手冊為準。

| 現象 | 常見原因 | 先查的指令 |
| --- | --- | --- |
| 連線遭拒、無法寫入 | 權限不足、防火牆阻擋、SMB 版本不符 | `icacls "C:\Scan"`、`net share Scan` |
| 找不到主機 | 使用電腦名稱而非 IP，名稱解析失敗 | 主機欄改填 IP |
| 路徑不存在 | 共用名稱打錯或大小寫不符 | `net share` |
| 驗證失敗 | 帳密錯誤、使用者名稱未加前綴 | `hostname`、`net user scan` |

## 常見狀況與處理

### 權限確認

```
icacls "C:\Scan"
net share Scan
```

前者應出現 `scan:(OI)(CI)(M)`，後者權限欄應有 `scan, CHANGE`。缺任何一項都會導致寫入失敗。

### 密碼已到期

```
net user scan
```

「密碼到期日」若非「從不」，重設密碼並設定為永不過期：

```
net user scan 新密碼
powershell -Command "Set-LocalUser -Name 'scan' -PasswordNeverExpires $true"
```

變更後記得同步更新事務機端的認證設定。

### 網路類型為公用

防火牆規則僅套用於私人與網域設定檔，網路顯示為 `Public` 時規則不生效：

```
powershell -Command "Get-NetConnectionProfile"
```

### IP 變動

```
ipconfig /all
```

「已啟用 DHCP：是」代表位址可能變動。處理方式依序為：

1. 請網路管理者在路由器設定 DHCP 保留
2. 手動指定 DHCP 範圍外的位址，設定前先 ping 確認未被占用
3. 改用事務機本身的儲存空間，或掃描至電子郵件

### 防毒軟體攔截

先暫時停用即時防護測試一次，確認是否為防毒所致，測試後立即恢復。

確認是防毒攔截時，需要加入兩處例外：

- **防火牆模組**：將事務機 IP 加入信任裝置，或允許 TCP 445 輸入連線
- **即時掃描模組**：將 `C:\Scan` 加入掃描排除，避免大型檔案寫入期間被鎖定

企業版防毒通常由管理主控台統一派送政策，單機修改會被覆蓋，需由資訊管理人員處理。例外範圍僅開放單一 IP 與單一資料夾，不要開放整個網段或磁碟。

### SMB 版本不符

```
powershell -Command "Get-SmbServerConfiguration | Select EnableSMB1Protocol,EnableSMB2Protocol"
```

較舊的事務機僅支援 SMB 1.0，而 Windows 10 / 11 預設停用。優先升級事務機韌體；無法升級時，改用其他傳輸方式較為妥當。基於安全性考量，不建議長期啟用 SMB 1.0。

## 連線測試

不確定問題出在電腦端或事務機端時，從同網段另一台電腦測試：

```
\\電腦IP\Scan
```

輸入 `電腦名稱\scan` 與密碼，能開啟並寫入檔案，代表電腦端設定正確，問題在事務機端的填寫內容。
